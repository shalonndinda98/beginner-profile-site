# My First Website

A simple responsive personal website built with plain **HTML**, **CSS**, and **JavaScript**.

## Files

- `index.html` — the page structure and content
- `styles.css` — colors, layout, responsive design, and animations
- `script.js` — mobile navigation and the current footer year

## Run locally

Open `index.html` directly in a browser, or use a local development server such as VS Code's Live Server extension.

## Customize it

1. Replace the name and text in `index.html`.
2. Update the colors at the top of `styles.css`.
3. Replace `hello@example.com` with your own email address.
4. Add links to your real projects in the project cards.

No build tools or frameworks are required.
